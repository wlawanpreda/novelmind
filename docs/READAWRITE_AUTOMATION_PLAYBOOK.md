# 📘 ReadAWrite Automation Playbook & Postmortem (คู่มือการแก้ปัญหาและการทำงาน)

เอกสารฉบับนี้รวบรวมปัญหาทางเทคนิค พฤติกรรมของระบบ **ReadAWrite** และแนวทางการแก้ไขที่ได้ทำไปแล้ว เพื่อป้องกันไม่ให้เกิดปัญหาซ้ำในการอัปโหลดนิยายเรื่องต่อๆ ไปในอนาคต

---

## 🛑 1. ปัญหาการแสดงผล Markdown (.md) ไม่รองรับ (CKEditor 5)

### ❌ ปัญหาที่พบ:
- ReadAWrite ใช้ **CKEditor 5 (HTML Rich-Text Editor)** ไม่ใช่ Markdown Engine
- เมื่อส่งข้อความจากไฟล์ Markdown (`.md`) เข้าไปตรงๆ ระบบจะแสดงตัวอักษรดิบ เช่น:
  - `## ตอนที่ 2: แมวหายในห้องปิดตาย` (แสดงเครื่องหมาย `##` หลุดออกมา)
  - `**คุณหญิงระเบียบ**` (ไม่กลายเป็นตัวหนา แต่แสดง `**` คาไว้)
  - `*(กลยุทธ์...)*` (แสดงเครื่องหมายดอกจัน)
- มีชื่อตอนซ้ำซ้อน 2 ชั้น (ชั้นแรกจากหัวข้อของเว็บ และชั้นที่สองจากบรรทัดแรกของเนื้อหา)

### ✅ วิธีแก้ถาวร (Implemented):
1. ติดตั้งไลบรารี `markdown` ในสภาพแวดล้อม `.venv`
2. สร้างฟังก์ชัน `text_to_html(text)`:
   - **ตัดบรรทัดแรกที่ขึ้นต้นด้วย `#` หรือ `##` ออกอัตโนมัติ** เพื่อไม่ให้หัวข้อซ้ำกับ Title ของเว็บ
   - แปลงเนื้อหาเป็น Semantic HTML ด้วย `markdown.markdown(clean_text, extensions=['extra', 'nl2br'])`
   - ผลลัพธ์ที่ได้จะเป็น `<p>`, `<strong>`, `<em>`, `<blockquote>` ที่ถูกต้อง 100%
3. ส่งข้อมูลเข้า CKEditor 5 โดยตรงผ่าน Instance:
   ```javascript
   const editor = document.querySelector(".ck-editor__editable").ckeditorInstance;
   editor.setData(htmlContent);
   ```

## 🛑 2. ปัญหานิยายซ้ำ / แบบร่างว่างเปล่า (Duplicate Empty Drafts)

### ❌ ปัญหาที่พบ:
- หากสคริปต์หยุดทำงานระหว่างทดสอบ หรือมีการรันซ้ำ จะเกิดหน้าร่างนิยายเปล่าที่มี `0 ตอน` ซ้อนกับเรื่องจริงที่มี `10 ตอน`

### ✅ วิธีแก้ถาวร (Implemented):
1. **ระบบ Pre-check ก่อนสร้าง:** สคริปต์จะค้นหาในหน้า `action=main_manage_article` ก่อนเสมอ หากพบเรื่องชื่อเดียวกัน จะดึง `article_id` เดิมมาใช้ทันที ไม่สร้างเรื่องใหม่ซ้ำ
2. **คำสั่งลบแบบร่างที่ไม่ได้ใช้ (Automated Purge):**
   ```javascript
   $.ajax({
       method: "POST",
       url: "?action=manage_article&token=",
       data: {
           article_guid: target_guid,
           manage: "delete",
           article_type: "MULTI_CHAPTER",
           article_species: "FICTION",
           is_collaborator: 0
       }
   });
   ```

### ❌ ปัญหาที่พบ:

### ✅ วิธีแก้ถาวร (Implemented):

## 🛑 4. ปัญหาฟอร์มสร้างเรื่อง: หมวดหมู่, นามปากกา และภาพปก

### 4.1 นามปากกา (Pen Name Validation)
- **พฤติกรรม:** บัญชีใหม่ที่ยังไม่มีนามปากกา จะไม่สามารถกด Save นิยายได้ (`#author_guid` ว่าง)
- **การแก้ปัญหา:** 
  - ลงทะเบียนนามปากกา **PJ** (`author_guid: 7279cede10fa551f91c258317ac1e356`) เข้าสู่ระบบของ ReadAWrite เรียบร้อย
  - สคริปต์จะผูกนามปากกา `PJ` ให้กับทุกเรื่องโดยอัตโนมัติ

### 4.2 การเลือกหมวดหมู่ (Category Taxonomy)
- **พฤติกรรม:** การเปลี่ยนค่า `#category_id` ใน DOM ตรงๆ จะไม่ทำงาน เพราะ ReadAWrite ผูกเงื่อนไขกับออบเจกต์หมวดหมู่ภายใน (`q[cat_id]`)
- **การแก้ปัญหา:**
  - เรียกใช้ฟังก์ชันภายในของ ReadAWrite:
    ```javascript
    setCategory("สืบสวน", "61", "87");
    ```
  - เพื่ออัปเดตทั้งป้ายชื่อหมวดหมู่, ตัวแปร Validation และซ่อน Error Alert อย่างถูกต้อง

### 4.3 โมดอลตัดภาพปกบังปุ่มบันทึก (Cropper Modal Interception)
- **พฤติกรรม:** เมื่ออัปโหลดไฟล์ภาพปกผ่าน `#upload_character` หน้าต่างตัดภาพ (Cropper) จะเด้งขึ้นมาและมีฉากหลังบังปุ่ม `#btnSaveArticle` ทำให้คลิกไม่ไป
- **การแก้ปัญหา:**
  - สั่งยืนยันการตัดภาพ `chatStory.cropToImgCharacter()`
  - ปิดโมดอล `#modal_upload_character_img` และลบ `.modal-backdrop` ออกจาก DOM ทันที

## 🛑 5. ช่องทางการรันคำสั่งที่ปลอดภัย (Standard Execution)

เพื่อให้การอัปโหลดเรื่องถัดไปทำได้อย่างราบรื่น 100%:

```bash
# 1. ตรวจสอบสถานะการเชื่อมต่อ
python3 web_novel_uploader.py --status

# 2. ตรวจสอบเนื้อหาและตอนก่อนส่งจริง (Dry Run)
python3 web_novel_uploader.py "ชื่อเรื่อง" --dry

# 3. อัปโหลดขึ้นระบบจริงอัตโนมัติ
python3 web_novel_uploader.py "ชื่อเรื่อง"
```
